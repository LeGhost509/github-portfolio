## How to Publish on GitHub Pages
1. Create a public repository named `github-portfolio`.
2. Upload these files.
3. Go to **Settings → Pages**.
4. Select branch `main` and folder `/ (root)`.
5. Save. Your site will be available at `https://LeGhost509.github.io/github-portfolio`.
