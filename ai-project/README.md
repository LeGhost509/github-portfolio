**Student:** Yves Bail  
**Course:** COSC 4272 Senior Seminar

## Project Overview
A small Python utility that helps generate and refine professional portfolio content (About Me drafts, project descriptions, and skills gap suggestions). The tool was developed with AI-assisted coding and prompt engineering. It demonstrates practical use of modern AI tools for software development while remaining fully local and dependency-light.

## Features
- Generate structured About Me paragraphs
- Suggest project description improvements
- Simple skills-gap checklist
- Export results to Markdown

## Technologies
- Python 3.10+
- Standard library only (no external packages required)

## How to Run
```bash
python ai_portfolio_helper.py
```

## AI Development Process
This project was created with significant AI assistance:
1. Initial requirements defined by the student.
2. Multiple prompts used to generate code structure, refine logic, and improve documentation.
3. Manual review and testing performed after each AI suggestion.
4. Final code cleaned and documented for submission.
